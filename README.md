2、在弹出的终端窗口中输入如下命令，然后回车执行：

irm https:**//**massgrave.dev**/**get | iex



3、系统会自动执行相关脚本，然后显示如下弹框，我们按下键盘“**2**”键进行 **Office** 激活。



4、然后按下“**1**”开始激活。
